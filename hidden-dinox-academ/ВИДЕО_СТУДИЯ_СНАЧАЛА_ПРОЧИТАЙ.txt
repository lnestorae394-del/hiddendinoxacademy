VIDEO STUDIO + CLOUDFLARE R2 — как обновить staging (пошагово)

ЧТО ИЗМЕНИЛОСЬ: файлы Video Studio теперь хранятся в Cloudflare R2 (не в Firebase Storage). Firebase остаётся для входа и базы. Переход Firebase на Blaze не нужен.

ШАГ 1. Скопируйте файлы из этого архива в папку проекта (с заменой существующих).
ШАГ 2. Откройте Терминал и выполните (подставьте путь к вашей папке проекта):
    cd ~/путь/к/hidden-dinox-academy
    npm install
  (команда обновит package.json и package-lock.json — AWS SDK для R2)
ШАГ 3. Отправьте на GitHub (подключённая к Render ветка staging):
    git add .
    git commit -m "Video Studio: Cloudflare R2"
    git push
ШАГ 4. Render → ваш сервис hidden-dinox-video-staging → Environment — проверьте переменные:
    VIDEO_STUDIO_ENABLED = 1
    VIDEO_STUDIO_STORAGE = r2
    VIDEO_STUDIO_ORIGIN  = https://hidden-dinox-video-staging.onrender.com
    R2_ENDPOINT          = https://<ID_аккаунта>.r2.cloudflarestorage.com   (БЕЗ имени бакета!)
    R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY  (секреты вводите только в Render)
    R2_BUCKET            = hidden-dinox-videos
    R2_REGION            = auto
  Если Build Command = "npm ci" — замените на "npm install". Если сборка просит новее Node — добавьте NODE_VERSION = 22.
ШАГ 5. Manual Deploy → Deploy latest commit.
ШАГ 6. Cloudflare → R2 → hidden-dinox-videos → Settings → CORS Policy → Add CORS policy → вставьте содержимое файла deploy/r2-cors.json → Save.
ШАГ 7. Откройте https://hidden-dinox-video-staging.onrender.com/academy/admin/video-studio.html
  • Сверху — жёлтый список «Не всё настроено», если чего-то не хватает (там точная причина).
  • Настройки → Диагностика → строка «Хранилище видео» должна быть зелёной: «Cloudflare R2 подключено».
ШАГ 8. Загрузите небольшой файл (20–50 МБ) для проверки, затем большой.
Подробно: docs/VIDEO_STUDIO.md. Production и основной Render этим архивом не затрагиваются.
