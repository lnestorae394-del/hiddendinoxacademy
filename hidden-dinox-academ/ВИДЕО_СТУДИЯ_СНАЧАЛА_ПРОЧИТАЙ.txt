HIDDEN DINOX VIDEO STUDIO — КАК ЗАПУСТИТЬ (самостоятельный сайт)

Подробно: docs/STANDALONE.md (переменные Render, Firebase, роли). Кратко:

ШАГ 1. В папке проекта выполните:   npm install
ШАГ 2. Firebase Console (проект hidden-dinox-video-staging): включите Email/Password, добавьте домен
        hidden-dinox-video-staging.onrender.com в Authorized domains, скопируйте веб-конфигурацию и создайте ключ сервисного аккаунта.
ШАГ 3. Правила Firestore:   cd deploy && npx firebase-tools deploy --only firestore --project hidden-dinox-video-staging
ШАГ 4. Render: команда запуска  node vs-server.js  (или Docker: deploy/Dockerfile.render). Переменные — по таблице в docs/STANDALONE.md.
        Ключи вводите только в панели Render и никому не отправляйте.
ШАГ 5. Откройте https://hidden-dinox-video-staging.onrender.com — страница входа. Зарегистрируйтесь, затем назначьте себя владельцем
        (VIDEO_STUDIO_OWNER_UID или код настройки на странице /setup — см. docs/STANDALONE.md).
ШАГ 6. Telegram (по желанию): VIDEO_STUDIO_TELEGRAM_ENABLED=1, VIDEO_STUDIO_TELEGRAM_BOT_TOKEN, VIDEO_STUDIO_TELEGRAM_WEBHOOK_SECRET,
        VIDEO_STUDIO_TELEGRAM_OWNER_CHAT_ID. Без них остальное работает без Telegram.
