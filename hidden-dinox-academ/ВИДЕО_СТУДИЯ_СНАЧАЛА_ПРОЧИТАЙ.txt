VIDEO STUDIO 2.0 + CLOUDFLARE R2 — как обновить staging (пошагово)

ШАГ 1. Скопируйте файлы из архива в папку проекта (с заменой существующих).
  (Если вы обновляете архивом «только изменённые файлы»: старый файл public/academy/admin/video-studio.js больше не нужен — его можно удалить.)
ШАГ 2. В Терминале (подставьте путь к проекту):
    cd ~/путь/к/hidden-dinox-academy
    npm install
  (обновит package.json и package-lock.json — AWS SDK для R2)
ШАГ 3. Отправьте на GitHub (ветка, подключённая к Render staging):
    git add .
    git commit -m "Video Studio 2.0: R2, новый интерфейс"
    git push
ШАГ 4. Render → hidden-dinox-video-staging → Environment. Проверьте переменные:
    VIDEO_STUDIO_ENABLED = 1
    VIDEO_STUDIO_STORAGE = r2
    VIDEO_STUDIO_ORIGIN  = https://hidden-dinox-video-staging.onrender.com
    R2_ENDPOINT          = https://<ID_аккаунта>.r2.cloudflarestorage.com   (БЕЗ имени бакета!)
    R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY   (вводите только в Render)
    R2_BUCKET = hidden-dinox-videos      R2_REGION = auto
  Если Build Command = "npm ci" — замените на "npm install". Если просит новее Node — добавьте NODE_VERSION = 22.
ШАГ 5. Manual Deploy → Deploy latest commit.
ШАГ 6. Cloudflare → R2 → hidden-dinox-videos → Settings → CORS Policy → Add → вставьте содержимое deploy/r2-cors.json → Save.
ШАГ 7. Откройте https://hidden-dinox-video-staging.onrender.com/academy/admin/video-studio.html
  • В верхней панели метка хранилища: зелёная «R2 подключено» — всё хорошо; красная — нажмите на неё.
  • Настройки → Хранилище → «Проверить соединение»: при ошибке страница покажет HTTP-статус, причину и подсказку (что исправить в Render или Cloudflare).
  • Затем «Тест записи и чтения»: проверит запись, чтение, ссылку, загрузку двумя частями, CORS и ETag.
  • Если нужна помощь — пришлите текст сообщения со страницы (без ключей и токенов).
ШАГ 8. Загрузите небольшой файл (20–50 МБ), затем большой.
Подробно: docs/VIDEO_STUDIO.md. Production и основной Render этим архивом не затрагиваются.

НОВОЕ В ЭТОЙ ВЕРСИИ (необязательные переменные Render):
  VIDEO_STUDIO_FFMPEG_TIMEOUT_MIN = 30   (таймаут одной команды ffmpeg)
  VIDEO_STUDIO_REMOTE_INPUT = 0          (выключить чтение исходника по ссылке при сборке; по умолчанию включено для записей от 256 МБ)
  VIDEO_STUDIO_REMOTE_MIN_MB = 256       (порог размера для чтения по ссылке)
Раздел «Очередь» теперь показывает живой монитор обработки: этап, время, измеренный прогресс, предупреждения.
