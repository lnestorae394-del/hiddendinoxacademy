ЭТО ПОЛНЫЙ ПРОЕКТ HIDDEN DINOX ACADEMY С УЖЕ ВСТРОЕННОЙ VIDEO STUDIO. Ничего накладывать и применять не нужно.

1) Скопируйте содержимое этой папки в вашу папку проекта (или залейте в GitHub) вместо старого кода.
2) В Render добавьте переменные окружения (ключ вводите только в панели Render, никому не пересылайте):
     VIDEO_STUDIO_ENABLED = 1
     GROQ_API_KEY         = (ваш ключ Groq)
     VIDEO_STUDIO_ORIGIN  = https://hiddendinox.com
   Уже существующие TELEGRAM_BOT_TOKEN, ADMIN_TELEGRAM_ID, ANTHROPIC_API_KEY используются как есть.
3) FFmpeg: в Render выберите Environment = Docker и Dockerfile Path = deploy/Dockerfile.render
   (или выполните  npm install ffmpeg-static ffprobe-static  и закоммитьте package.json и package-lock.json).
4) Deploy. Откройте админ-панель → Video Studio.
   • Если что-то не настроено, СВЕРХУ СТРАНИЦЫ появится жёлтый список «Не всё настроено» с точной причиной (нет FFmpeg, нет ключа и т.д.).
   • В логах Render при старте будет строка «Video Studio: не заданы переменные окружения: ...», если чего-то не хватает.
5) Настройки → Диагностика → «Настроить CORS хранилища»; блок Telegram: «Проверить подключение», нажать Start у бота, «Отправить тестовое сообщение».
6) Подробно: docs/VIDEO_STUDIO.md. Без VIDEO_STUDIO_ENABLED=1 сайт работает ровно как раньше.
