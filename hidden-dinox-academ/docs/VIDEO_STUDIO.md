# HIDDEN DINOX VIDEO STUDIO

Закрытый раздел админ-панели: загрузка записи TikTok LIVE → ИИ находит сильные моменты → вертикальные ролики 1080×1920 с хуком, субтитрами и оформлением Hidden Dinox → редактор → экспорт → **готовый MP4 приходит вам в Telegram**.
Открывается из админ-панели (пункт «Video Studio»), использует ту же сессию Firebase, доступен только admin и super_admin (проверка на сервере).

## Как это работает
1. **Загрузка.** Файл (MP4/MOV до 5 ГБ) уходит из браузера прямо в Firebase Storage по защищённой возобновляемой сессии, которую выдаёт сервер (через Express видео не идёт). Загрузку можно отменить; при обрыве выберите тот же файл — она продолжится с места остановки. Повторная загрузка того же файла отклоняется.
2. **Проверка видео** (FFmpeg): формат, кодеки, звук, длительность, пробное декодирование. Битый файл отклоняется и удаляется.
3. **Анализ** (по вашему подтверждению расхода): звук → Groq Whisper (слова с таймкодами) → Claude выбирает сильные моменты (только номера фраз) → код проверяет ответ (цитаты есть в расшифровке, хуки без обещаний, длительность, пересечения) и вырезает клипы. Выдуманное отклоняется. Если сильных моментов нет — клипов не будет.
4. **Редактор:** предпросмотр 9:16, текст хука (и 3 варианта от ИИ), субтитры по словам (текст, время, ключевые слова, границы блоков), обрезка начала и конца на шкале, масштаб и сдвиг кадра, оформление (цвета, размеры, положение, логотип), «Точный предпросмотр» и «ПЕРЕСОБРАТЬ ВИДЕО».
5. **Экспорт и Telegram:** сборка MP4 (громкость −16 LUFS, 1080×1920) и автоматическая отправка в Telegram методом `sendVideo`. Успех фиксируется только после подтверждения Telegram (`message_id`).
Очередь заданий хранится в Firestore: после перезапуска сервера незавершённое подхватывается (аренда задания истекает за 2 минуты), временные файлы удаляются, исходная запись при ошибках не теряется.

## Новые переменные окружения
| Переменная | Нужна | Зачем |
|---|---|---|
| `VIDEO_STUDIO_ENABLED=1` | да | включает модуль (без неё сайт работает как раньше) |
| `GROQ_API_KEY` | да | распознавание речи (Groq Whisper) |
| `ANTHROPIC_API_KEY` | уже есть | Claude. Отдельный ключ только для Video Studio: `VIDEO_STUDIO_ANTHROPIC_API_KEY` (расход всё равно считается отдельно от AI-ментора) |
| `TELEGRAM_BOT_TOKEN`, `ADMIN_TELEGRAM_ID` | уже есть | бот проекта и ваш Chat ID по умолчанию |
| `VIDEO_STUDIO_ORIGIN` | желательно | адрес сайта, с которого разрешена загрузка (например `https://hiddendinox.com`; несколько — через запятую). Если не задана, разрешается адрес самой страницы |
| `FFMPEG_PATH`, `FFPROBE_PATH` | если нужно | путь к FFmpeg, если его нет в PATH (см. «FFmpeg на Render») |
Необязательные: `VIDEO_STUDIO_BUCKET` (по умолчанию бакет проекта), `VIDEO_STUDIO_MONTHLY_BUDGET_USD` (5), `VIDEO_STUDIO_JOB_BUDGET_USD` (1), `VIDEO_STUDIO_MAX_UPLOAD_GB` (5), `VIDEO_STUDIO_MAX_DURATION_MIN` (120), `VIDEO_STUDIO_MAX_CONCURRENT` (1), `VIDEO_STUDIO_RUNNER=0` (не обрабатывать в этом экземпляре), `VIDEO_STUDIO_TMP`, `VIDEO_STUDIO_JOB_MAX_RUNTIME_MIN` (90), `VIDEO_STUDIO_TG_LIMIT_BYTES`. Лимиты можно менять и на странице (Настройки).

## Подключение и запуск (по шагам)
1. Положите файлы из архива в проект и примените патч (см. README_INSTALL.txt): меняются только `academy/index.js` (одно подключение) и `public/admin/admin.js` (пункт меню).
2. **FFmpeg на Render.** Обычная среда Node его не содержит. Выберите один способ:
   - *Docker (надёжнее):* в настройках сервиса Render выберите Environment: Docker, Dockerfile Path `deploy/Dockerfile.render` (внутри ffmpeg с libass).
   - *Пакеты npm:* выполните `npm install ffmpeg-static ffprobe-static`, закоммитьте `package.json` и `package-lock.json`. Подходит ли эта сборка для субтитров (libass), покажет раздел «Диагностика» в настройках Video Studio.
3. Добавьте переменные окружения (таблица выше), затем **Manual Deploy**.
4. Firebase: на тарифе Blaze включите Storage. Правила: добавьте строки из `deploy/storage.rules.snippet` и `deploy/firestore.rules.snippet` к существующим (не заменяя их). Срок хранения файлов (30 дней): `gsutil lifecycle set deploy/bucket-lifecycle.json gs://<бакет>`.
5. **CORS бакета** (нужен для загрузки из браузера): откройте Video Studio → Настройки → Диагностика → «Настроить CORS хранилища». Если не получится (нет прав), страница покажет готовую команду `gsutil`.
6. Откройте админ-панель → **Video Studio** → Настройки: проверьте «Диагностику» (FFmpeg, libass, ключи).
7. **Telegram (один раз):** Настройки → Telegram → «Проверить подключение» → откройте бота по ссылке и нажмите **Start** (бот не может написать первым) → вставьте свой Chat ID (узнать: бот @userinfobot) → «Отправить тестовое сообщение».
8. Загрузите запись LIVE → «Найти лучшие моменты» (покажет оценку расхода) → выберите клип → отредактируйте → «ПЕРЕСОБРАТЬ ВИДЕО». Готовый ролик придёт в Telegram автоматически.

## Безопасность
- Все маршруты `/api/video-studio/*`: проверка токена Firebase, блокировки, роли admin/super_admin на сервере; студент, ментор и модератор получают отказ. Файлы закрыты правилами, выдаются ссылками на 15 минут.
- Сессия загрузки создаётся только для доверенного адреса; размер, тип и заголовок файла проверяются; путь в хранилище задаёт сервер.
- Токен бота и ключи берутся только из окружения; в Firestore, ответы API и журнал не попадают.
- Расход на ИИ считается отдельно от AI-ментора; лимиты жёсткие (на задачу, в месяц, по длительности): превышение отклоняется до траты.

## Ограничения
- Рендер идёт на сервере Academy (1 задача одновременно). На слабом тарифе Render 1080×1920 собирается медленно; рекомендуется план с 2 ГБ памяти. Для отдельной «рабочей» машины запустите второй экземпляр с `VIDEO_STUDIO_RUNNER=1`, а на основном задайте `VIDEO_STUDIO_RUNNER=0`.
- Telegram: бот принимает файлы до 50 МБ. Если ролик больше, система сначала пробует сжать его, затем присылает ссылку (статус «Отправлена ссылка», не «Доставлено»).
- Качество выбора моментов и точность распознавания зависят от Groq и Claude; цены поставщиков заданы в настройках сервера и не сверялись автоматически.

## Тесты
`sh tests/video-studio-run-all.sh` — строгий запуск (пропущенный тест не считается пройденным). Нужны Node ≥ 18, ffmpeg с libass, Python 3 + Playwright/Chromium (для проверки страницы; флаг `--no-ui` пропускает её). Все внешние сервисы в тестах — подделки (Groq, Claude, Telegram Bot API, Firestore, Storage, вход Firebase): **реальные сервисы тестами не проверяются**.

## Откат
Уберите `VIDEO_STUDIO_ENABLED` (или удалите добавленную строку в `academy/index.js`) — маршруты и обработка выключатся. Данные (`videoStudio*`, папка `video-studio/` бакета) остаются; удалять их можно только вручную.
