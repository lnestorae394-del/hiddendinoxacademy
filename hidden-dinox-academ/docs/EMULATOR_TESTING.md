# Проверка правил Firestore на эмуляторе (без production)

Проект в эмуляторе называется `demo-hd-rules`: имя с префиксом `demo-` не может обратиться к реальному Firebase. Реальные ключи и `FIREBASE_KEY` для этой проверки НЕ нужны и не должны быть заданы.

## Однократная подготовка (на вашем компьютере)
1. Установите Java 11 или новее (нужна эмулятору Firestore): `java -version` должен ответить.
2. В папке проекта: `npm install --save-dev firebase-tools @firebase/rules-unit-testing`
   (это изменит package.json и package-lock.json — закоммитьте их.)

## Запуск
```
npx firebase emulators:exec --only firestore --project demo-hd-rules "node --test tests/emulator/firestore-rules.emulator.test.js"
```
Ожидается: тест пройден (аноним, обычный пользователь и «админ» с клиента получают отказ на чтение и запись во всех коллекциях и в неописанной коллекции).
Если вместо «пройден» написано «skipped» — эмулятор или пакет не найдены.

## Чего эта проверка НЕ делает
Не проверяет живые правила вашего проекта (они в консоли Firebase) и не проверяет серверный код (Admin SDK правила обходит по определению). Применять правила к Production можно только вручную и после проверки на эмуляторе.
